# Genshin Archives

Genshin Archives is a Vue 3 + Tailwind CSS application that provides an interactive database for characters, regions, artifacts, and weapons from the game **Genshin Impact**. Users can search and filter characters by elements, weapon types, and rarity.

---

## Features

- **Character Search** – Quickly search characters by name.
- **Advanced Filtering** – Filter characters by:
  - Element (Anemo, Geo, Electro, Dendro, Hydro, Pyro, Cryo)
  - Weapon Type (Sword, Claymore, Polearm, Bow, Catalyst)
  - Rarity (4★, 5★)
- **Dynamic Lists** – Displays regions, artifacts, and weapons with detailed stats.
- **Responsive Design** – Fully responsive layout using Tailwind CSS.
- **Interactive UI** – Hover effects, modals for filters, and smooth transitions.

---

## Tech Stack

- **Frontend**: Vue 3 (`<script setup>`)
- **Styling**: Tailwind CSS
- **State Management**: Vue's `ref` and `computed`
- **Components**: Reusable layouts via `AppLayout.vue`
